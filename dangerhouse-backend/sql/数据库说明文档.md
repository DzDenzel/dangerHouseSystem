## 1. 数据库概览

### 1.1 数据库信息

- **数据库名称**：dangerhouse
- **字符集**：utf8mb4
- **排序规则**：utf8mb4_0900_ai_ci
- **存储引擎**：InnoDB

### 1.2 表清单

| 序号 | 表名            | 中文名称    | 说明          |
|----|---------------|---------|-------------|
| 1  | user          | 用户表     | 存储系统用户信息    |
| 2  | role          | 角色表     | 存储系统角色信息    |
| 3  | user_role     | 用户角色关系表 | 用户与角色的多对多关系 |
| 4  | building      | 建筑档案表   | 存储建筑基本信息    |
| 5  | detection     | AI检测记录表 | 存储检测任务和结果   |
| 6  | image         | 检测图片表   | 存储检测图片信息    |
| 7  | report        | 检测报告表   | 存储检测报告信息    |
| 8  | operation_log | 操作日志表   | 存储系统操作日志    |

### 1.3 ER关系图

```
user ─── user_role ─── role
  │
  └─── detection ─── image
         │
         └─── report

building ─── detection
    │
    └─── report
```

## 5. 外键约束

| 从表            | 外键名                      | 从表字段         | 主表        | 主表字段 | 删除规则     |
|---------------|--------------------------|--------------|-----------|------|----------|
| user_role     | fk_ur_user_id            | user_id      | user      | id   | CASCADE  |
| user_role     | fk_ur_role_id            | role_id      | role      | id   | CASCADE  |
| detection     | fk_detection_building_id | building_id  | building  | id   | CASCADE  |
| detection     | fk_detection_user_id     | user_id      | user      | id   | SET NULL |
| image         | fk_image_detection_id    | detection_id | detection | id   | CASCADE  |
| report        | fk_report_detection_id   | detection_id | detection | id   | CASCADE  |
| report        | fk_report_building_id    | building_id  | building  | id   | CASCADE  |
| operation_log | fk_log_user_id           | user_id      | user      | id   | SET NULL |

### 级联规则说明

- **CASCADE**：删除主表记录时，自动删除从表关联记录
- **SET NULL**：删除主表记录时，从表关联字段置为NULL

## 附录

### A. SQL脚本执行说明

#### 完整部署（首次安装）

```bash
mysql -u root -p < dangerhouse_v3.0.sql
```

#### 完整部署（含基础业务数据）

```bash
mysql -u root -p < dangerhouse_v3.0_with_data.sql
```

> `dangerhouse_v3.0_with_data.sql` 已合并角色、用户、用户角色、建筑、检测、图片、报告等基础数据，
> 不包含操作日志历史数据。

### B. 数据库连接配置

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/dangerhouse?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
    username: root
    password: your_password
    driver-class-name: com.mysql.cj.jdbc.Driver
```

### C. 版本更新日志

#### v3.2 (2026-04-13)

- 新增 `dangerhouse_v3.0.sql`，将角色权限分级与建筑归属字段整合为完整初始化脚本
