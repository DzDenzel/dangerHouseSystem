# 危房智能检测系统后端接口联调文档

> 用途：前后端联调  
> 基础路径：`http://localhost:8080/api`  
> 认证方式：`Authorization: Bearer {token}`  
> 文档范围：当前项目已落地接口，仅保留接口说明、请求参数、响应参数与示例

---

## 1. 通用约定

### 1.1 统一响应结构

除文件流下载接口外，后端统一返回以下结构：

```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "timestamp": 1710000000,
  "requestId": "2d08f771-2b88-4d95-9aa2-xxxx"
}
```

### 1.2 分页响应结构

分页接口的 `data` 统一为：

```json
{
  "records": [],
  "total": 12,
  "current": 1,
  "size": 10,
  "pages": 2
}
```

字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `records` | Array | 当前页数据 |
| `total` | Long | 总记录数 |
| `current` | Long | 当前页码 |
| `size` | Long | 每页条数 |
| `pages` | Long | 总页数 |

### 1.3 认证与端限制

| clientType | 允许角色 |
| --- | --- |
| `APP` | `USER`、`INSPECTOR` |
| `WEB` | `ADMIN` |

登录时长：

| rememberMe | 有效期 |
| --- | --- |
| `false` 或不传 | 1 小时 |
| `true` | 3 天 |

### 1.4 常用状态字典

检测状态：

| 值 | 说明 |
| --- | --- |
| `CREATED` | 已创建 |
| `READY` | 已上传图片，待开始检测 |
| `PROCESSING` | 检测中 |
| `COMPLETED` | 检测完成 |
| `FAILED` | 检测失败 |
| `CANCELLED` | 已取消 |

风险等级：

| 值 | 说明 |
| --- | --- |
| `A` | 基本安全 |
| `B` | 有风险点 |
| `C` | 局部危房 |
| `D` | 整体危房 |

建筑结构类型：

| 值 | 说明 |
| --- | --- |
| `BRICK_MIX` | 砖混结构 |
| `CONCRETE` | 钢筋混凝土 |
| `STEEL` | 钢结构 |
| `BRICK_WOOD` | 砖木结构 |
| `OTHER` | 其他 |

用户状态：

| 值 | 说明 |
| --- | --- |
| `1` | 启用 |
| `0` | 禁用 |

## 2. 认证接口

### 2.1 登录

- 方法：`POST`
- 路径：`/auth/login`
- 权限：无需登录

请求体：

```json
{
  "account": "admin",
  "password": "123456",
  "rememberMe": true,
  "clientType": "WEB"
}
```

请求参数：

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `account` | String | 是 | 用户名 / 手机号 / 邮箱 |
| `password` | String | 是 | 密码 |
| `rememberMe` | Boolean | 否 | 是否记住我 |
| `clientType` | String | 是 | `APP` 或 `WEB` |

响应 `data`：

```json
{
  "id": 1,
  "token": "eyJhbGciOiJIUzI1NiJ9.xxx",
  "roles": ["ADMIN"],
  "username": "admin",
  "phone": "13800138000",
  "email": "admin@dangerhouse.com",
  "nickname": "系统管理员",
  "avatar": "/uploads/avatar/1.jpg",
  "lastLoginTime": "2026-04-15T10:00:00",
  "createdAt": "2026-03-01T10:00:00",
  "updatedAt": "2026-04-15T10:00:00",
  "status": 1
}
```

响应字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | Long | 用户 ID |
| `token` | String | JWT |
| `roles` | String[] | 角色编码数组 |
| `username` | String | 用户名 |
| `phone` | String | 手机号 |
| `email` | String | 邮箱 |
| `nickname` | String | 昵称 |
| `avatar` | String | 头像地址 |
| `lastLoginTime` | String | 最后登录时间 |
| `createdAt` | String | 创建时间 |
| `updatedAt` | String | 更新时间 |
| `status` | Integer | 用户状态 |

## 10. 联调建议

### 10.1 Web 登录

- 管理员登录时 `clientType` 传 `WEB`
- 非管理员账号会被后端直接拒绝

### 10.2 App 登录

- 普通用户、检测员登录时 `clientType` 传 `APP`
- 管理员账号会被后端直接拒绝

### 10.3 数据权限

- 普通用户：
  - 建筑接口只返回 `ownerUserId = 当前用户` 的建筑
  - 检测接口只返回自己的检测记录
  - 报告接口只允许访问自己的报告
- 检测员：
  - 可查看全部建筑
  - 可查看全部检测记录
- 管理员：
  - 可访问后台管理接口

### 10.4 联调重点

- `POST /auth/login`：注意 `clientType`
- `GET /buildings`：普通用户与检测员返回范围不同
- `GET /detections`：普通用户与检测员返回范围不同
- `GET /reports/{id}`、`GET /reports/{id}/download`：普通用户存在归属校验
