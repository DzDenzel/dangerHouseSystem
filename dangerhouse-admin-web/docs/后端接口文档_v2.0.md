## 接口规范

### 1. 统一响应结构

所有接口返回数据统一遵循以下 JSON 格式：

```json
{
  "code": 200,          // 状态码 (200表示成功)
  "message": "success", // 提示信息
  "data": {},           // 业务数据
  "timestamp": 1710000000, // 响应时间戳 (秒)
  "requestId": "c8e3f1b1..." // 请求唯一标识 ID
}
```

### 2. 分页规范

**请求参数：**

- `page`: 当前页码（默认 1）
- `pageSize`: 每页数量（默认 10）

**响应数据结构 (`data` 字段内部)：**

```json
{
  "total": 120,     // 总记录数
  "page": 1,        // 当前页码
  "pageSize": 10,   // 每页数量
  "records": []     // 数据列表
}
```

### 3. 认证方式

- Header: `Authorization: Bearer {token}`
- Token 通过登录接口获取，有效期默认 24 小时。

## 认证授权接口

### 1. 用户登录

- **接口名称:** 用户登录
- **路径:** `/api/auth/login`
- **方法:** `POST`
- **Content-Type:** `application/json`
- **鉴权:** 无需鉴权

**请求参数:**

| 字段名 | 类型 | 必填 | 说明 | 示例值 |
|---|---|---|---|---|
| account | String | 是 | 账号（用户名/手机号/邮箱） | `admin` |
| password | String | 是 | 密码 | `123456` |

**响应示例:**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "token": "eyJhbGciOiJIUzUxMiJ9...",
    "roles": ["ADMIN"],
    "username": "admin",
    "nickname": "管理员",
    "avatar": "http://...",
    "lastLoginTime": "2026-03-12T10:00:00",
    "status": 1
  }
}
```

### 2. 用户注册

- **接口名称:** 用户注册
- **路径:** `/api/auth/register`
- **方法:** `POST`
- **Content-Type:** `application/json`
- **鉴权:** 无需鉴权

**请求参数:**

| 字段名 | 类型 | 必填 | 说明 | 示例值 |
|---|---|---|---|---|
| username | String | 是 | 用户名 (4-20位) | `testuser` |
| password | String | 是 | 密码 (6-20位) | `123456` |
| phone | String | 否 | 手机号 | `13800138000` |
| role | String | 否 | 角色编码 (默认 USER) | `USER` |

**响应示例:**

```json
{
  "code": 200,
  "message": "注册成功",
  "data": {
    "id": 101,
    "username": "testuser",
    "phone": "13800138000",
    "role": "USER",
    "createTime": "2026-03-12T10:00:00"
  }
}
```

### 3. 检查用户名

- **接口名称:** 检查用户名是否可用
- **路径:** `/api/auth/check-username/{username}`
- **方法:** `GET`
- **鉴权:** 无需鉴权

**响应示例:**

```json
{
  "code": 200,
  "data": true // true: 可用, false: 已存在
}
```

## 检测管理接口

**核心流程：** `创建任务` -> `上传图片` -> `启动检测` -> `查询结果`

### 1. 创建检测任务

- **接口名称:** 创建检测任务
- **路径:** `/api/detections`
- **方法:** `POST`
- **鉴权:** 需要

**请求参数:**

| 字段名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| buildingId | Long | 是 | 关联建筑ID |
| description | String | 否 | 任务描述/备注 |

**响应示例:**

```json
{
  "code": 200,
  "data": {
    "id": 101,
    "status": "CREATED",
    "buildingId": 1,
    "createdAt": "2026-03-12T10:00:00"
  }
}
```

### 2. 上传检测图片

- **接口名称:** 上传检测图片
- **路径:** `/api/detections/{id}/images`
- **方法:** `POST`
- **Content-Type:** `multipart/form-data`
- **鉴权:** 需要

**请求参数:**

| 字段名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| images | File[] | 是 | 图片文件数组 (支持多张，单次上限10张) |

**响应示例:**

```json
{
  "code": 200,
  "data": [
    { "id": 1, "imagePath": "/uploads/xxx.jpg", "imageType": "ORIGINAL" },
    { "id": 2, "imagePath": "/uploads/yyy.jpg", "imageType": "ORIGINAL" }
  ]
}
```

### 3. 启动检测

- **接口名称:** 启动检测
- **路径:** `/api/detections/{id}/start`
- **方法:** `POST`
- **鉴权:** 需要
- **说明:** 触发后端调用 Python AI 服务进行批量检测与联合分析。

**响应示例:**

```json
{
  "code": 200,
  "message": "检测任务已启动",
  "data": {
    "id": 101,
    "status": "COMPLETED", // 或 PROCESSING (若异步)
    "riskLevel": "B",
    "crackCount": 3,
    "damageRatio": 12.5
  }
}
```

### 4. 获取检测详情

- **接口名称:** 获取检测详情
- **路径:** `/api/detections/{id}`
- **方法:** `GET`
- **鉴权:** 需要

**响应示例:**

```json
{
  "code": 200,
  "data": {
    "id": 101,
    "buildingId": 1,
    "buildingName": "xx小区",
    "status": "COMPLETED",
    "riskLevel": "C",
    "crackCount": 5,
    "damageRatio": 18.5,
    "confidence": 92.0,
    "detectTime": "2026-03-12T10:05:00",
    "detectResult": { ... }, // 完整 AI 分析 JSON
    "images": [
      { "id": 1, "imagePath": "/orig/a.jpg", "resultImagePath": "/res/a_labeled.jpg" }
    ]
  }
}
```

### 5. 获取检测记录列表

- **接口名称:** 获取检测列表
- **路径:** `/api/detections`
- **方法:** `GET`
- **鉴权:** 需要

**请求参数:**

| 字段名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| page | Integer | 否 | 页码 |
| size | Integer | 否 | 每页条数 |
| buildingId | Long | 否 | 建筑ID |
| status | String | 否 | 状态 (COMPLETED/FAILED...) |
| riskLevel | String | 否 | 风险等级 (A/B/C/D) |
| startDate | Date | 否 | 开始日期 (yyyy-MM-dd) |
| endDate | Date | 否 | 结束日期 (yyyy-MM-dd) |

### 6. 取消/删除检测

- **取消任务:** `PUT /api/detections/{id}/cancel`
- **删除任务:** `DELETE /api/detections/{id}`

## 数据字典

### 风险等级规则 (v2.0)

| 风险等级 | 代码 | 损伤比例范围 | 说明 | 颜色标识 |
|---|---|---|---|---|
| **A** | A | < 5% | 无危险点（结构安全） | 🟢 绿色 |
| **B** | B | 5% - 15% | 有危险点（结构基本安全） | 🟡 黄色 |
| **C** | C | 15% - 30% | 局部危房（部分承重结构危险） | 🟠 橙色 |
| **D** | D | > 30% | 整幢危房（整体处于危险状态） | 🔴 红色 |

### 检测状态

- `CREATED`: 已创建
- `PROCESSING`: 检测中
- `COMPLETED`: 已完成
- `FAILED`: 失败
- `CANCELLED`: 已取消

## 错误码说明

| 错误码 | 说明 | 建议处理 |
|---|---|---|
| 200 | 成功 | 正常展示数据 |
| 400 | 请求参数错误 | 检查必填项或格式 |
| 401 | 未登录或 Token 失效 | 跳转登录页 |
| 403 | 无权限 | 提示权限不足 |
| 404 | 资源未找到 | 提示资源不存在 |
| 500 | 服务器内部错误 | 联系管理员 |
